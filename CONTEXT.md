# Contexto para o Repositório Response:

"Response é uma biblioteca Pure Kotlin projetada para substituir o Result padrão em fluxos
assíncronos complexos. Ela fornece um contrato semântico claro (Idle, Loading, Success, Failure) com
suporte nativo a metadados de paginação, tornando-a a parceira ideal para arquiteturas MVI e
bibliotecas de UI de alta performance."
